# Download single set of records for a single collection

Download single set of records for a single collection

## Usage

``` r
nc_single_dl(query, filter, timeout, token)
```

## Arguments

- query:

  List. Queries for server

- filter:

  List. Filter queries for server

- token:

  Character. Authorization token

## Value

the request (a list with 'result' and 'requestId')
